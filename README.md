One original one-line joke about office life (89 characters):

> I put 'per my last email' in my out-of-office reply so the argument continues without me.

"Per my last email" is the office's signature passive-aggressive opener; the turn is that the out-of-office reply — the one place meant to end conversations — is used to keep the argument going, without the author even being there.

## Run it

```sh
python3 main.py
```
